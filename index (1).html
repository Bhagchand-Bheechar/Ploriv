Info & Help

Search — Type in the address bar or home search. Default engine is Velox. Only related answers appear.

New Tab — Click the + next to your tabs (like Chrome), or the + on the home screen.

Bookmarks — Open a page → star in the address bar → Settings → Bookmarks to open later.

Host — Open ploriv.host.com from Preferences to claim a domain and deploy a site (optional image URL).

Private Tab — Settings → New Private Tab. History is only at ploriv.private.tab.history.com (when signed in).

Tab lock — Hover a tab → lock icon. Locked tabs cannot close and return after refresh until unlocked.

Account — Add account for cloud sync (Online → Synced when logged in).
